# ExamFlow Roadmap

This roadmap outlines the future direction of ExamFlow following the stable v2.0.0 release.

## v2.1.0 - AI Productivity Suite (In Progress)
Shift the primary user interaction from manual configuration to a conversational AI assistant.

- **Module 1: AI Chat Assistant:** The main entry point. Users can say "Create a Java mid-semester paper" or "Balance this blueprint" and the system orchestrates the actions.
- **Module 2: Smart Question Recommendation:** Proactive suggestions for questions that improve an exam's blueprint balance based on Bloom's level, difficulty, and past usage.
- **Module 3: Adaptive Blueprint Generator:** Generate a blueprint entirely from a natural language prompt (e.g., "Create a placement test for Java with 50 questions, medium difficulty, and 90 minutes").
- **Module 4: AI Report Generator:** Generate polished PDF reports analyzing exam quality, topic coverage, and difficulty distribution for administrators.

## v3.0.0 - Student Portal (Planned)
Close the loop by allowing students to take the exams directly on the platform.

- **Digital Test Taking:** A secure interface for students to take generated exams.
- **Automated Grading:** Auto-grade MCQ, True/False, and provide AI-assisted grading for Short Answer questions.
- **Student Analytics:** Dashboards for students to track their performance over time.
- **Anti-Cheat Measures:** Browser lockdown, tab tracking, and randomized question order per student.

## Future Exploration
- **LMS Integration:** Export exams directly to Canvas, Blackboard, or Moodle via LTI standards.
- **Collaborative Editing:** Google Docs-style real-time collaboration for teachers co-authoring an exam.
